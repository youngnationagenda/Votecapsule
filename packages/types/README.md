# @vote-capsule/types

Shared TypeScript types, interfaces, and enums used across all Vote Capsule™ services and applications.

## Usage

```typescript
import { PaginatedResponse, SystemRole, TenantType, CapsuleStatus } from '@vote-capsule/types';
```

## Contents

- Common API response types (`ApiResponse`, `PaginatedResponse`)
- Base entity interfaces
- Status enumerations for all platform entities
- System role definitions
- JWT payload types
- Auth token types
