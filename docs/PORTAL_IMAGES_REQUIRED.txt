  SECTION 1 — FAVICON (all 5 portals)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Each portal already has a favicon.svg as inline SVG code.
No action needed unless you want to replace with a custom logo.

  File name : favicon.svg
  Location  : apps/{portal-name}/public/favicon.svg
              (one copy per portal — replace all 5 the same way)
  Format    : SVG (square, 32×32 or 64×64 viewBox)
  Used for  : Browser tab icon

Portals:
  apps/party-web/public/favicon.svg
  apps/candidate-web/public/favicon.svg
  apps/admin-web/public/favicon.svg
  apps/observer-web/public/favicon.svg
  apps/authority-web/public/favicon.svg

  SECTION 2 — PARTY BRANDING (uploaded via Party Portal UI)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are NOT static files. Each political party uploads their
own logo and banner through the Party Portal → Profile → Branding.
They are stored in S3 and returned as URLs by the tenant API.

You (as party admin) upload these through the portal itself.
No need to name or place them manually.

  1. Party Logo
     Upload at  : Party Portal → Profile → Upload Logo
     Recommended: 400×400 px, PNG with transparent background
     Displayed  : Party profile page, portal header card

  2. Party Banner
     Upload at  : Party Portal → Profile → Upload Banner
     Recommended: 1200×400 px, PNG or JPG
     Displayed  : Top of party profile page

  NOTE: The admin portal (admin-web) reads these same URLs
  from the party settings API. Once a party uploads them via
  the party portal, admin-web shows them automatically.

  SECTION 3 — CANDIDATE PHOTOS (uploaded during registration)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are uploaded per candidate during nomination/registration.
Not static files — stored in S3 and returned as photographUrl.

  1. Candidate Headshot (photographUrl)
     Upload at  : Party Candidates page → Register Candidate → Photo
     Recommended: 400×400 px, JPG, candidate facing forward
     Displayed  : Candidate list rows (40×40 px rounded)
                  Nomination status page (64×64 px rounded)

  2. Candidate Symbol / Party Symbol (symbolUrl)
     Upload at  : Candidate registration form → Symbol
     Recommended: 200×200 px, PNG with transparent background
     Displayed  : Ballot reference views

  (upload to S3 bucket: votecapsule-campaign-assets)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are the product preview images shown in the Materials
Catalogue on both the Party Portal and Candidate Portal.

S3 BUCKET  : votecapsule-campaign-assets
S3 PATH    : suppliers/me-advertising/images/
NAMING RULE: The file name MUST EXACTLY match the material
             type code (all caps, underscores) followed by .jpg
             Example: A4_POSTER.jpg

FORMAT     : JPG preferred, PNG also works
SIZE       : 400×400 px (square), max 150 KB each
BACKGROUND : White or light grey

If an image is missing for a code, the portal shows the
built-in SVG icon instead — so missing images do not break
anything, they just look less polished.

  SECTION 6 — HOW TO UPLOAD TO S3
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open AWS Console → S3 → votecapsule-campaign-assets
2. Navigate to: suppliers/me-advertising/images/
3. Upload all 275 .jpg files
4. Set: public read access (ACL: public-read) OR
        use a CloudFront distribution in front of S3
5. The portal will automatically find them because
   the URL pattern is hard-coded as:
   https://s3.amazonaws.com/votecapsule-campaign-assets/
           suppliers/me-advertising/images/{CODE}.jpg

   If you use CloudFront, update the getS3ImageUrl() helper
   in these two files:
     apps/party-web/src/components/ProductImage.tsx
     apps/candidate-web/src/components/ProductImage.tsx

• File names are case-sensitive on S3. Use UPPER_CASE exactly
  as shown — e.g. A4_POSTER.jpg not a4_poster.jpg.

• If an image is missing for a product, the portal
  automatically falls back to the built-in coloured SVG icon.
  Nothing breaks — it just looks less professional.

• You do NOT need all 275 on day one. Start with the most
  common categories:
    Priority 1: PRINTED_MATERIALS (posters, flyers, banners)
    Priority 2: BRANDED_CLOTHING (t-shirts, caps)
    Priority 3: OUTDOOR_ADVERTISING (billboards, yard signs)
    Priority 4: PROMOTIONAL_ITEMS (mugs, bags, pens)

• Recommended image sources for generic product photos:
    - Shutterstock / Getty Images (licensed)
    - Unsplash / Pexels (free)
    - Your supplier's actual product photos (best quality)
    - AI-generated product mockups (fastest)

• You can update any image later simply by uploading a new
  file with the same name to the same S3 path. CloudFront
  cache will clear within 24 hours (or use an invalidation).
