# Capsule Agent Mobile App

**App:** agent-mobile
**Assigned to:** Future Phase (Phase 3)
**Status:** Scaffold only

## When Assigned
Stack: React Native + TypeScript + Expo
Primary users: Field agents at polling stations
Key features: Offline capture, SHA-256 hashing, image upload, sync queue

## Critical Requirements
- OFFLINE FIRST — must work without internet
- SHA-256 computed ON DEVICE at capture time
- Evidence stored locally until sync
- Only trusted devices (registered via Identity Service) can submit
